<h1>osTicket - Ticket Lifecycle: Intake Through Resolution</h1>
This lab demonstrates the complete lifecycle of a ticket, from intake to resolution, using the osTicket help desk system.<br />

<h2>Environments and Technologies Used</h2>

- Microsoft Azure (Virtual Machines)
- Remote Desktop
- osTicket

<h2>Operating Systems Used </h2>

- Windows 10 Pro</b> (21H2)

<h2>Ticket Lifecycle Stages</h2>

- Intake
- Assignment and Communication
- Working the Issue
- Resolution

<h2>Resolutions by Priority</h2>

1. Business Critical Outage should be set to "emergency".
2. Personal Computer Issues should be set to "high".
3. Equipement Request should be set to "normal".
4. Password Reset should be set to "least priority".

<p>
Admins receive ticket requests in their panel and can assign tickets to specific agents or teams based on the issue's urgency. Admins also set the ticket's severity level to align with Service Level Agreements (SLAs) and ensure prompt responses. In this example, Jane reviewed a ticket, assigned it to the System Administrators team, and marked it as an Emergency.
